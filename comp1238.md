## Week 2 - Bits and Bytes
- **Binary:** 1 bit = a 0 or 1, and 1 byte = 8 bits. Computers use binary (base 2) to represent data.
- **Memory:** RAM is volatile (loses data when power is off); SSDs and HDDs are non-volatile (keep data without power).
- **Number & Text Representation:** 8-bit unsigned numbers range from 0–255, while signed numbers range from −128 to 127. ASCII uses numbers to represent characters (e.g., 65 = 'A').

## Week 3 - Text Structures
- **Markdown vs. HTML:** Markdown uses simple symbols to format text (e.g., `**bold**`, `# Title`), while HTML uses tags (e.g., `<strong>bold</strong>`, `<h1>Title</h1>`).
- **Escaping & Structured Data:** Escaping prevents special characters from being interpreted as formatting (e.g., `\#` in Markdown). JSON stores structured data as key-value pairs (e.g., `{"key": "value"}`).
- **Unicode & UTF-8:** Unicode supports many more characters than ASCII. UTF-8 uses 1–4 bytes per character and is widely used on the internet; UTF-32 uses 4 bytes per codepoint.

## Week 4 - Keyboards and Editors
- **Text Editors vs. Word Processors:** Text editors (e.g., Notepad, VS Code) edit plain text and code, while word processors (e.g., Microsoft Word) focus on formatted documents. IDEs combine tools for software development.
- **Search Techniques:** `Ctrl + F` finds text, wildcards (`*`) match character sequences, and Regular Expressions (Regex) match patterns (e.g., `line\d+` finds "line" followed by digits).
- **VS Code & Vim:** VS Code supports extensions and multiple-cursor editing (`Ctrl + D`). In Vim, `:q!` quits without saving changes.

## Week 5 - CLI
- **Basic CLI Commands:** `ls` lists files, `cd` changes directories, `pwd` shows the current directory, `mkdir` creates directories, and `cp` copies files.
- **CLI Advantages:** Command Line Interfaces allow faster tasks, automation through scripts, remote access, and lower resource usage than many graphical interfaces (GUIs).
- **Remote Access & Pipes:** SSH securely connects to remote computers, `scp` securely copies files between computers, and piping (`|`) sends the output of one command into another command.
